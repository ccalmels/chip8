* Chip-8 interpreter
** Design
*** Memory
Originaly 4K, 512 first bytes are used for the interpreter.
Last 256 bytes are used for display refresh. The 96 bytes below were used for call stack.
| start |   end | size | usage       |
|-------+-------+------+-------------|
| 0x000 | 0x1FF |  512 | intepreter  |
| 0x200 | 0xE9F | 3232 |             |
| 0xEA0 | 0xEFF |   96 | stack       |
| 0xF00 | 0xFFF |  256 | framebuffer |
*** Registers
- PC program counter
- 16 8-bit data registers V0-VF. VF acts as a flag register.
- address register I, 12 bits.
*** Timers
Two decreasing timers at 60Hz.
- delay: for event
- sound: for sound effect
*** Input
Hex keyboard with 16 keys from 0 to F.
8, 4, 6, 2 keys are used for directions.
*** GFX
Original display resolution is 64x32 pixels. The Chip-8 only draw 8b wide sprite with height from 0 to 15. They are XORed with the corresponding screen pixels.
*** CPU
Not a real CPU. Opcodes are clocked at 500Hz.

** SuperChip-8
*** Memory
No more framebuffer or stack inside the memory: 0x200-0xFFF is available.
*** Display
HiRes mode: 128 x 64
*** New Opcode
- Switch resolution
- Scroll down, right, left
- Fx30 for HiRes font sprite
- Store/Load registers in an internal storage (not memory)
*** OpCode changes
- Quirks
  - VF Reset
  - memory index update (Fx55, Fx65)
  - shifting modification
  - different jump opcoce (Bxnn)
- Draw 16x16
*** Clock
Opcodes clocked at 1KHz or better.

** Xo-Chip
*** Memory
16K
*** Registers
- PC on 16 bits
- Index on 16 bits
*** Display
2 planes: so 4 colors
*** New Opcode
- Scroll up
- Load/Write registers at Index
- Load 16 bit value to Index
- Select display plane to draw into
- Load 16 bits pattern for audio frame
- Set audio pitch
